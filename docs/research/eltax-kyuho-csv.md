# 給与支払報告書・源泉徴収票の統一 CSV（eLTAX）の項目（取込日 2026-10-29）

出典: 地方税共同機構「給与支払報告書‐源泉徴収票の統一CSVレイアウト仕様書 令和07年分～」（https://www.lta.go.jp/documents/14256 、xlsx。資料一覧 https://www.lta.go.jp/support/documents/01/ ）、同サンプル（/documents/14259）、「各項目の記載に当たっての留意事項」（/documents/00078）。令和 8 年分の版は 2026-10-29 時点で未公開のため、令和 7 年分の項目に令和 8 年分の金額の要件を当てる（特定親族の下限 58 万円 → 62 万円）。

- 1 行 = 受給者 1 人、147 項目をカンマ区切り。`,` と `@` は値に使えない。年は和暦 2 桁（令和 8 年分は `08`）、元号は 昭和 1・大正 2・明治 3・平成 4・令和 5。
- 属性: 全角（e-Tax で使えない ℃ Å ⌒ ★ ☆ ♀ ♂ ♪ ♭ ♯ は不可）/ 半角（英数字・記号）/ 数字（半角数字）。金額は円の整数。
- 「H=eLTAX ○ / I=e-Tax ○」は、eLTAX が受け付ける項目と、eLTAX から e-Tax へ回す項目（源泉徴収票データ）。作成区分 `2`（国税・地方税の双方）で出すと源泉徴収票のみなし提出の扱いになる。
