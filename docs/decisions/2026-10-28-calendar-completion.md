# 期限は「完了」と「未完了」の 2 状態で片付け、左ナビに一覧を置く（S8）

- 状況: 期限（`CalendarItem`）は会計期間から規則で作られ、ホームの「やること」とメールで知らせる。完了を記録する手段がなく、済んだ期限・期限切れ・自社に当てはまらない期限（役員報酬を払わない期の社会保険の新規適用届など）がホームに残り続けていた。ホームに出るのは 7 日以内の期限だけで、一覧の入口もなかった。
- 決定（S8、2026-10-28）: 期限の一覧 `/calendar` を作り、各行を「完了にする」「未完了に戻す」で切り替える。状態は未完了と完了の 2 つで、当てはまらない期限も「完了にする」で片付ける（「対象外」の状態は作らない）。一覧は左ナビ「期限」（報告の後・請求の前）とスマホの「その他」から開く。給与の確定が作る納付の期限（[22 §7](../design/22-payroll.md)）は一覧に並べるだけで、完了は給与の画面の「納付を登録」「納付済みにする」に任せる。
- 理由: schema の `completedAt` / `completedBy` だけで足り、migration・同期・通知の規則を変えずに済む。対象外かどうかは監査ログ（誰がいつ完了にしたか）で追える。ホームに出ない先の期限も見て片付けられるよう、常に開ける入口が要る。給与の納付は完了と仕訳が対なので、期限の画面で戻せると二重に納付を登録できてしまう。
- 影響: [24](../design/24-calendar.md)（新規）、[05 §1](../design/05-ui-ux.md) のナビの表、[07 §4](../design/07-operations.md)、[14 §9](../design/14-reports.md)。対象外を区別する必要が出たら、状態の列を足す migration で別に決める。
