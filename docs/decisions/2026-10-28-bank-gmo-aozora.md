# 法人口座は GMO あおぞらネット銀行（D3）

- 状況: 自社口座へ直接つなげる API を公式に提供している銀行は GMO あおぞらネット銀行（標準 API 無償・sunabar）と三井住友（Web21・料金非公開）だけ。
- 決定（owner 2026-10-28）: 口座 API のある銀行でよい。GMO あおぞらネット銀行の一択で進める。
- 理由: API と CSV が揃い、sunabar で先に開発できる。費用が無償。
- 影響: 設立直後に口座開設と API 接続の申込（契約まで最大 2 か月）。v1 は CSV、v2 で API。[04 §2](../design/04-integrations.md)
