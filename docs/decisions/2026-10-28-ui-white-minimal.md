# 配色はできるだけシンプルな白基調。Notion・STUDIO を参考（D14）

- 決定（owner 2026-10-28）: 配色はできるだけシンプルに白基調。Notion や STUDIO の画面を参考にする。
- 理由: 内部の作業ツールで、装飾より読みやすさと速さ。
- 影響: ページ背景と面は白、区切りは薄いグレーの線と余白、文字は近い黒と 1 段階の muted グレー、色は primary（NIHO の緑）を CTA と焦点だけに使い、状態は文字とアイコンで表す。`apps/web/app/globals.css` のトークンを白基調に更新し、モックの色（クリーム）は使わない。[05 §3](../design/05-ui-ux.md)
