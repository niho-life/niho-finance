# Stripe は NIHO株式会社の法人アカウントを新設し、NIHO アプリの決済を移す（D4）

- 状況: 既存の niho-platform / niho-kamakura は会社名義だが、現在の事業主体（別の法人）の名義。日本で本人確認済みのアカウントは事業形態を編集で変えられない。
- 決定（owner 2026-10-28）: NIHO株式会社の法人アカウントを新設し、NIHO アプリの決済はその法人アカウントを主体にするよう移転する。
- 理由: 名義の変更ができず、会社の売上・手数料・請求書の受け皿を会社名義に揃える必要がある。
- 影響: 本システムが帳簿に入れる Stripe の口座は新しい法人アカウント（と、その Connect で会社が運営する拠点のアカウント）だけ。既存アカウントの履歴は旧事業主体の帳簿で、取り込まない。移転の計画（platform の作り替え・連結アカウントの再接続・顧客と決済手段のコピー・Webhook と鍵）は niho-app 側の Epic。[04 §1.1](../design/04-integrations.md)、[08 §5](../design/08-roadmap.md)
