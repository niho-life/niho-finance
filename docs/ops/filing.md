# 決算書の提出と申告用データの手順

第 n 期の決算が終わってから、計算書類の承認・申告・決算公告までに行う手順。画面と出力の仕様は [17 決算書と申告用データ](../design/17-financial-statements.md)、時期は [07 運用](../design/07-operations.md)。第 1 期の申告書は税理士にスポットで依頼する（[09 D6](../design/09-decisions.md)）。

## 1. 決算書を確かめる（期末〜2 か月以内）

1. 決算（`/closing`。#14）のチェックリストを上から済ませ、期を締める。
2. `決算書`（`/closing/statements?fy=<n>`）を開き、上の「確認」が空であることを見る。残っていれば各行の入口から直す。
   - 「勘定科目コードが決まっていない科目があります」: 設定 › 勘定科目 でその科目の勘定科目コードを入れる（コード表は `packages/reports/data/etax/`）。
   - 「仮払消費税・仮受消費税の残高が残っています」: 決算整理の消費税の精算を登録する（課税の期だけ）。
3. 「決算書の設定」で発行済株式の総数・注記・事業報告の文を会社の実態に合わせて直し、保存する。雛形のままにしない。
4. 計算書類一式の PDF を書き出し、貸借対照表・損益計算書・株主資本等変動計算書・個別注記表・附属明細書・事業報告を読み合わせる。

## 2. 財務諸表 CSV を国税庁の CSV ファイルチェックコーナーで確かめる

e-Tax で受け付けられる形かどうかを、提出の前に国税庁の [CSV ファイルチェックコーナー](https://www.e-tax.nta.go.jp/csvcheck/csvcheck.htm) で確かめる。1 ファイルずつの確認は事前準備セットアップが要らない。推奨環境は macOS なら Safari だけ（Windows は Edge / Chrome）で、macOS の Chrome は「チェック対象・読込方法の選択」の次で環境チェックに止められ先へ進めない（2026-10-28 に確認）。Mac では Safari で開く。

1. `決算書` の「書き出し」で「財務諸表 CSV（e-Tax）」の zip を書き出して展開する。`HOT010_3.0_BS.csv`・`HOT010_3.0_PL.csv`・`HOT010_3.0_SS.csv`・`HOT010_3.0_NT.csv` の 4 つ。ファイル名は変えない（命名規則から財務諸表の種類が判定される）。
2. CSV ファイルチェックコーナーを開き、「財務諸表」→「1. 1ファイルずつ読み込む」→「次へ」。
3. 「様式種別」で財務諸表を選ぶ（対象事業年度・様式は選ばなくてよい）。
4. 「参照」で 1 つ目の CSV を選び「読込」。
5. 「チェック完了通知」が出れば合格。「CSV ファイルチェックエラー一覧」が出たら、エラーの行番号と内容を控え、次のどちらかで直す。
   - 文字のエラー（JIS 第 1・第 2 水準外）: 科目名・会社名・注記の文から該当の文字を直す（画面は書き出しの前に止めるはずなので、起きたら不具合として Issue にする）。
   - 階層番号・勘定科目コード・行区分のエラー: 不具合として Issue にし、エラー一覧（CSV で保存できる）を添える。e-Tax ソフト上で直して送ることもできるが、次の期も同じ誤りが出るので必ず元を直す。
6. 残りの 3 ファイルも同じように確かめる。
7. 結果をこの文書の §6 の記録に 1 行足す（日付・期・ファイル・結果・エラーの内容）。開発中のフィクスチャで確かめたときも同じ表に書く。

## 3. 申告に渡す

- 税理士に渡すもの: 計算書類一式の PDF、財務諸表 CSV の 4 ファイル、勘定科目内訳の元データ（CSV）、消費税の集計（CSV。課税の期）、固定資産の明細（#14）、仕訳帳・総勘定元帳（報告 › 書き出し）。
- 自分で e-Tax ソフト（インストール版）に取り込むとき（第 2 期以降の目標）: 「帳票一覧」→「財務諸表等の組み込み」で 4 つの CSV を組み込み、帳票イメージで表示されることを確かめる（e-Tax ソフト操作マニュアル第 21 章）。

## 4. 計算書類の承認と決算公告（定時株主総会の後）

1. 定時株主総会（株主 1 名なら書面決議）で計算書類を承認する。承認日を「決算書の設定」の「株主総会の日」に入れる。
2. 「決算公告の掲載日」を入れ、「決算公告」の HTML を書き出す。
3. HTML を niho.life の決算公告のページに置く（ファイル 1 つで外部の読み込みはない）。置いた URL を「決算公告の URL」に入れる。
4. 掲載期限（株主総会の日から 5 年）まで消さない。期限は `決算書` の画面に出る。

## 5. 年 1 回の確認（決算の前）

- e-Tax ホームページの「財務諸表の CSV 形式データの作成方法」と勘定科目コード表の更新日を見る。`packages/reports/data/etax/hot010-3.0/2019/manifest.json` の `lastModified` と違えば、新しい版として取り込む（`packages/reports/data/etax/README.md`）。既存の版は書き換えない。
- 勘定科目内訳明細書・消費税の様式の改正（令和 8 年 4 月 1 日以後終了事業年度分など）を税理士と確かめる。
