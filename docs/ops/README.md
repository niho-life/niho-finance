# 運用文書

電子帳簿保存法のシステム関係書類のうち「操作説明書」「事務手続を明らかにした書類」と、その対応表をここに置きます。設計（概要書・仕様書）は [`../design/`](../design/00-overview.md)。

| 文書 | 内容 |
| --- | --- |
| [electronic-records-compliance.md](electronic-records-compliance.md) | 電子帳簿保存法の要件対応表（規則 → 機能 → 証跡）、システム関係書類の所在、税務調査での提示手順 |
| [electronic-records-policy.md](electronic-records-policy.md) | 電子取引データの訂正及び削除の防止に関する事務処理規程の雛形。制定は 設定 › 証憑の規程 |
| [documents-operations.md](documents-operations.md) | 証憑の操作説明書（保存・整理・紐づけ・検索・無効化と差し替え・月次） |

実物の規程（商号・責任者入り）、会社の実データ、日次エクスポートの写しは非公開側（[06 §5](../design/06-architecture.md)）に置き、ここには書きません。
