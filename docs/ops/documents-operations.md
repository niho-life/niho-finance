# 証憑の操作説明書

電子帳簿保存法の「操作説明書」に当たる文書です（[要件対応表](electronic-records-compliance.md) §1）。画面の仕様は [13 証憑](../design/13-documents.md)、月次の流れは [07 運用](../design/07-operations.md) §2。

## 1. 保存する（アップロード・撮影）

- PC: 証憑 を開き、上のドロップゾーンにファイルを落とすか「選ぶ」で選びます。複数まとめて選べます。画像（JPEG・PNG・WEBP・HEIC）・PDF・CSV、1 ファイル 20 MB まで。
- スマホ: 下タブ中央のカメラ → 「撮影」でその場で撮るか、「選ぶ」で写真やファイルを選びます。1 枚なら保存が終わると詳細が開きます。
- 保存の流れ: ブラウザがファイルの SHA-256 を計算し、サーバーが同じファイルがないかを確かめてから送信します。送信後にサーバーがもう一度 SHA-256 と形式を確かめ、合ったものだけを登録します。
- 同じファイルを 2 回保存しようとすると、送信せずに「保存済みのファイルと同じ」と出て、既存の証憑を開けます。
- 保存した時点では種別（撮影は 領収書、CSV は 明細書）だけが入り、日付・金額・取引先は空です。受信箱には、紐づけがないものと、紐づけ済みでも日付・金額・取引先のどれかが空（未整理）のものが並びます。

## 2. 整理する（日付・金額・取引先）

- 受信箱の行を開き、右の項目を入れます。種別・取引年月日・金額（税込）・取引先（取引先マスタから選ぶか「その他」で名前を入力）・登録番号（T と 13 桁）・メモ。各項目は入力を終える（blur / Enter）と保存され、右上に「保存済み」と出ます。
- 取引年月日・取引金額・取引先の 3 つが電子帳簿保存法の検索の項目です。保存した月の翌月末までに入れます（規程 第 10 条）。
- 紐づけで埋めることもできます（§3）。

## 3. 紐づける（仕訳・明細・請求書）

- 金額を入れると、詳細の「同じ金額・近い日付」に、同じ金額で日付が近い明細（未処理を先に）と取引（仕訳）が出ます。「紐づける」で結びます。証憑の日付・金額・取引先が空なら相手の値で埋まります（明細は日付・金額と振込人名、取引は日付・金額と取引先）。
- 候補にない相手は、取引の詳細（取引 › No. n）や明細の行から証憑を選んで結びます（S3・S5 の画面）。
- 1 つの証憑を複数の仕訳に、1 つの仕訳に複数の証憑を結べます（カードの明細書など）。
- 間違えたら「外す」。紐づけが 0 になると「未紐づけ」に戻ります。
- 「この証憑から取引を登録」で、日付・金額・取引先を入れた状態で取引の新規画面が開きます（S3 の merge 後）。

## 4. 検索する

- 証憑 › すべて で、取引年月日の範囲・金額の範囲・取引先・種別・キーワード（ファイル名・メモ）を組み合わせて検索します。条件は URL に入るので、再読み込みや共有で同じ結果になります。
- 無効にした証憑も「すべて」と「無効」に理由つきで出ます。
- 「索引簿を書き出す」で、いまの条件の CSV（証憑 ID・取引年月日・金額・取引先・登録番号・種別・状態・無効の理由・仕訳番号・明細・ファイル名・形式・SHA-256・保存日時・保存者・メモ）を保存します。Excel でそのまま開けます（UTF-8 BOM）。

## 5. 無効にする・差し替える

- 削除はありません。誤って保存したもの、重複、取引先が再発行したものは「無効にする」で理由を書いて無効にします。ファイルも紐づけも残り、検索にも出ます。無効は元に戻せません。
- 内容を直したファイル（再発行された請求書など）は「差し替える」。理由と新しいファイルを選ぶと、新しい証憑が元の項目と紐づけを引き継ぎ、元は「差し替え: 理由」で無効になります。
- 無効・差し替えの記録（誰が・いつ・なぜ）は詳細の履歴と 設定 › 監査ログ に残り、規程 第 9 条の申請書・報告書の代わりになります。

## 6. 毎月すること

1. 銀行・カードの CSV を取り込む（明細の取込）。取り込んだ CSV は自動で証憑（明細書）として保存され、取込の結果と証憑の詳細から互いに辿れます。受信箱には出ません。
2. Stripe のダッシュボードから前月の請求書（手数料の請求書）を PDF でダウンロードし、証憑に保存して種別を「受領した請求書」にします。アカウントが 2 つあるので 2 枚です。
3. 受信箱を上から空にします（整理 → 紐づけ、または無効）。
4. 紙でしか受け取っていない領収書は、撮影して保存した上で、紙の原本を月ごとの封筒に入れて 7 年保管します（スキャナ保存は行わないため、写真は帳簿づけと検索の補助です）。
5. 月を締める前に、受信箱が 0 件であることを確かめます（ホームの「やること」にも件数が出ます）。

## 7. 設定 › 証憑の規程

- 初回: 施行日・管理責任者（既定は代表者）・処理責任者を入れて保存します。全文が商号入りで表示され、印刷できます。印刷して押印したものを非公開側に保管します。
- 文面の版が上がったときは画面に案内が出るので、読み直して施行日を入れ直します。

## 8. 困ったとき

- 「ファイルの中身が形式と合いません」: 拡張子と中身が違うファイルです。元のアプリから書き出し直すか、PDF にして保存します。
- 「保存済みのファイルと同じ」: 同じファイルが既にあります。開いて項目や紐づけを確かめます。別の取引なら、取引先が発行し直したファイルを使うか、メモにその旨を書いて同じ証憑に複数の仕訳を結びます。
- プレビューが出ない: HEIC と CSV はプレビューできません。「ファイルを開く」でダウンロードして見ます。
- スマホでカメラが開かない: ブラウザのカメラの許可を確かめます。許可しなくても「選ぶ」から写真を選べます。
