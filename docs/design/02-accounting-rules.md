# 02. 会計処理の規則

台帳（`packages/ledger`）が守る規則と、日々の仕訳の型を定めます。税務の数値（税率・特例の期限）は [03](03-compliance.md) と `docs/research/jp-requirements.md` を正とし、ここでは「システムがどう扱うか」を書きます。

## 1. 基本規則（MUST）

- 複式簿記。1 仕訳の借方合計と貸方合計は一致する。金額は JPY の整数。
- 発生主義を基本にするが、月次は「明細ベース」で運用し、売掛・未払の計上は請求書（受託）とカード・Stripe の残高で自動的に生まれる分に限る。期末に前払・未払・前受を整理する。
- 登録した仕訳は変えない。訂正は反対仕訳＋新仕訳（[01 §3](01-domain-model.md)）。削除は論理削除。アプリだけでなく DB のトリガーで確定後の UPDATE / DELETE を禁止する。
- 月次の締め（`lockedThrough`）以前には登録・訂正できない。締めは月初のルーチンで進める。
- すべての収益・費用の行にセグメントを付ける。BS 科目は任意（拠点の現金・敷金は付ける）。
- 税区分はすべての行に付ける（免税の期でも）。免税の期は仮受・仮払の行を作らず、`taxAmount` だけ保持する。

## 3. 税区分と消費税

- 税区分のコードは [01 §1](01-domain-model.md) の `TaxCategory`。経過措置の控除割合は期間で変わるため、税区分は「インボイスなし」を別コードにし、控除割合は日付で引く。
- 内税額の計算: 税込額 × 税率 ÷ (100 + 税率)、1 円未満切り捨て。行ごとに計算し、請求書は税率ごとに 1 回だけ端数処理する。
- 免税の期: 税込経理。仮受・仮払の行は作らない。レポートの消費税集計は「もし課税事業者なら」の参考値として出す。
- 課税の期（本則）: 税抜経理を既定にし、登録時に仮受消費税・仮払消費税の行を自動で足す。期末に差額を未払消費税等へ振り替える。
- 課税の期（簡易）: 税込経理のまま、売上の税区分だけで納付額を計算する。
- 期の途中で登録（免税 → 課税）した場合は、登録日で期を 2 つに分けず、`FiscalYear.consumptionTax` を `general` にした上で登録日より前の行を集計から除く。

## 4. 代表的な仕訳の型

### 4.1 設立

| 取引 | 借方 | 貸方 |
| --- | --- | --- |
| 資本金の払込（設立日） | 普通預金 50,000 | 資本金 50,000 |
| 登録免許税（役員が立替） | 創立費 150,000 | 役員借入金 150,000 |
| 定款認証（役員が立替） | 創立費 | 役員借入金 |
| 設立後〜開業の費用 | 開業費 | 役員借入金 / 普通預金 |
| 役員への精算 | 役員借入金 | 普通預金 |

創立費・開業費は繰延資産として計上し、償却（初年度に全額、または 5 年）は決算整理で選ぶ（[09 D11](09-decisions.md)）。

### 4.2 Stripe

Stripe の口座は「Stripe 残高」（資産）。balance transaction の `reporting_category` ごとに明細を作り（総額と手数料は別行）、ルールで仕訳にする。詳細は [04 §1](04-integrations.md)。

| balance transaction | 借方 | 貸方 | 税区分 | 備考 |
| --- | --- | --- | --- | --- |
| `charge`（総額） | Stripe 残高 | 売上高（会費など） | sales_10 | 決済日（JST）で売上 |
| `fee`（手数料。charge の手数料と月次の調整） | 支払手数料（税抜）＋消費税額 | Stripe 残高 | purchase_10 | 税抜と税額を分けて保持。根拠は Stripe の月次の適格請求書 |
| `refund` | 売上高 | Stripe 残高 | sales_10 | 返金 |
| `payout` | 普通預金 | Stripe 残高 | - | 口座間振替。銀行の入金明細と照合 |
| `platform_earning`（platform 側の application fee） | Stripe 残高（platform） | 内部取引 | - | 自社拠点からの手数料は内部取引（[09 D5](09-decisions.md)）。他社拠点からは売上高 プラットフォーム |
| 拠点側の application fee | 内部取引 | Stripe 残高（拠点） | - | 同上 |
| `dispute` / `dispute_reversal` | 雑損失 または 売上高 | Stripe 残高 | | 紛争手数料は支払手数料 |

自社名義でない拠点（他のホスト）の決済は、platform の application fee だけが自社の売上になる。拠点アカウントそのものは取り込まない。

### 4.3 銀行・カード・現金

| 取引 | 借方 | 貸方 |
| --- | --- | --- |
| 振込入金（受託） | 普通預金 | 売掛金（請求書に消込） |

| カード決済（購入時） | 費用科目 | 未払金（カード） |

口座間の振替（payout・カード引落・現金の預入）は 2 つの明細を 1 つの仕訳に結び、両方を `transfer` にする。

## 5. 期末処理

決算画面（v2）のチェックリストの順。

1. 未処理の明細 0 件、未紐づけの証憑 0 件（または理由つきで無視）。
2. 残高の照合: 銀行の残高証明・Stripe の残高・現金の実査と、帳簿の残高の一致。差異は仮払金 / 雑収入・雑損失で整理し理由を残す。
3. 減価償却: 固定資産台帳から当期分の仕訳。少額（10 万円未満）は取得時に費用、一括償却資産（20 万円未満）は 3 年、中小企業者の特例（30 万円未満）は即時（期限は [03](03-compliance.md)）。
4. 繰延資産の償却（創立費・開業費）。
5. 前払・未払・前受・貯蔵品。
6. 消費税（課税の期だけ）。
7. 法人税等の計上。均等割は赤字でも発生し、第 1 期は月割り。
8. 期末の締め: `FiscalYear.status = closed`。決算振替仕訳（収益・費用 → 繰越利益剰余金）を `closing` として作る。
9. 翌期の開始残高は仕訳から導出する（開始仕訳は作らない）。

## 6. 不変条件のテスト（`packages/ledger`）

- 任意の仕訳列に対して、全科目の借方合計 = 貸方合計。
- `internal` 科目の残高は常に 0。
- 締め以前の日付の登録・取消は例外を投げる。
- 取消は元の仕訳と反対仕訳の合計が 0 になる。
- 連番は期ごとに 1 から単調増加し、欠番がない。
- 税込額からの内税計算は、税率ごとの合計で 1 円以上ずれない（請求書）。
- 試算表の資産合計 = 負債 + 純資産 + 当期純利益。
