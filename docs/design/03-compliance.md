# 03. 法令対応

消費税・インボイス制度、電子帳簿保存法、法人税等の申告、会社法の計算書類、固定資産、役員報酬と社会保険について、「制度の要点」と「システムでどう満たすか」を定めます。制度の根拠・出典・未確認事項は [`../research/jp-requirements.md`](../research/jp-requirements.md)。この文書は論点の整理で、税務・社会保険の判断は税理士・社労士の確認を前提にします。制度は年度ごとに変わるため、税率・限度額・期限はコードに埋めず日付つきのデータで持ちます。

## 1. この会社の位置づけ（2026-10-28 時点）

| 論点 | 結論 | 設計への含意 |
| --- | --- | --- |
| 消費税の納税義務 | 資本金 5 万円の新設法人なので第 1 期・第 2 期は免税の見込み（インボイス登録や課税事業者選択をしなければ）。第 3 期は第 1 期の課税売上高を年換算して 1,000 万円超なら課税 | `FiscalYear.consumptionTax` を期ごとに持つ。免税の期は税込経理固定 |
| 2 割特例 | 適用期間（〜2026-09-30 を含む課税期間）の外なので使えない。3 割特例は個人のみ | 2 割特例の計算は実装しない |
| 第 1 期の長さ | 設立日〜2027-03-31（約 5 か月）。月割の規定（少額特例の上限・法人税の 800 万円・均等割・防衛特別法人税の控除）に効く | `FiscalYear` の月数を導出し、月割の共通関数を持つ |
| 青色申告 | 設立から 3 か月を経過した日の前日までに承認申請（例: 11/10 設立 → 2027-02-09）。少額減価償却資産の特例の前提 | 届出カレンダーの最優先項目 |
| 社会保険 | 役員報酬を払うなら設立から 5 日以内に新規適用（1 人でも強制）。報酬ゼロなら適用を受けられない | 役員報酬の有無を会社の状態として持ち、警告する |

## 2. 消費税とインボイス

### 2.1 登録の判断と時期

- 登録すると登録日から課税事業者になる（免税のままでは適格請求書を発行できない）。設立事業年度の末日（2027-03-31）までに「課税期間の初日から登録を受けようとする旨」を書いて申請すれば設立日に遡って登録できる。つまり **第 1 期の末まで判断を先送りできる**（[09 D1](09-decisions.md)）。
- 登録した場合の方式は本則課税か簡易課税（第 5 種・みなし仕入率 50% の見込み）。簡易課税の届出も第 1 期は期末までに出せばその期から適用。原則 2 年継続。
- 買手としての影響: 免税事業者等からの仕入は 2026-10-01 以降 70% しか控除できない（下の経過措置）。自社が登録しないと、課税事業者の取引先の控除が減る。

### 2.2 経過措置と予定されている改正（日付つきデータで持つ）

| 項目 | 期間と内容 |
| --- | --- |
| 免税事業者等からの仕入の控除割合 | 80%（〜2026-09-30）→ 70%（2026-10-01〜2028-09-30）→ 50%（〜2030-09-30）→ 30%（〜2031-09-30）→ 0%。同一取引先からの年間仕入の上限 1 億円 |
| 少額特例（税込 1 万円未満は帳簿のみで控除） | 〜2029-09-30。基準期間の課税売上高 1 億円以下の事業者 |
| 返還インボイス | 税込 1 万円未満の値引き・返品は交付不要 |
| 飲食料品の消費税率 1% | 2027-04-01〜2029-03-31 の予定。法案は提出済みで 2026-10-28 時点で未成立。成立したら第 2 期の全期間に影響（簡易課税の特例あり） |

`TaxRateRule`（税区分コード・適用期間・税率・控除割合）に上の表を入れ、取引日と取引先の登録状況で自動判定する。法案が成立するまで 1% の行は無効にしておく。

### 2.3 適格請求書の記載事項（請求書モジュール・v2）

- 発行者の名称と登録番号、取引年月日、取引内容（軽減税率の対象はその旨）、税率ごとの対価の額と適用税率、税率ごとの消費税額、宛名。
- 端数処理は 1 枚の請求書につき税率ごとに 1 回（明細ごとの端数処理の合算は不可）。
- 発行した写しは 7 年保存（PDF を証憑 `invoice_out` として保存）。修正インボイス・返還インボイスも同じ。
- 適格簡易請求書（不特定多数向け）は宛名不要で、税額か税率のどちらかでよい。NIHO アプリの領収書はこちらに当たる。

### 2.4 帳簿側の記載（買手）

- 帳簿に相手方の名称・取引年月日・内容・対価を残す（仕訳行の `partnerId`・`description`・`amount` で満たす）。
- 帳簿のみで控除できる特例（1 万円未満、公共交通機関 3 万円未満、自販機、出張旅費など）は、税区分に「特例の種類」を持たせ、帳簿に「特例の対象である旨」を出力する。

### 2.5 税区分の設計

税区分は「申告書の集計区分」として固定コードで持ち（課税売上 10% / 軽減 8% / 非課税売上 / 対象外売上 / 輸出免税 / 課税仕入 10% / 8% / インボイスなし / 非課税仕入 / 対象外仕入 / 帳簿のみ特例 / 簡易課税の事業区分）、税率・控除割合・適用期間は `TaxRateRule` に分ける。勘定科目の既定税区分は初期値にすぎず、取引ごとに上書きできる（地代家賃は事務所なら課税・住宅なら非課税、租税公課は対象外、など）。

## 3. 電子帳簿保存法

### 3.1 3 つの区分とこのシステムの立場

| 区分 | 義務 / 任意 | このシステム |
| --- | --- | --- |
| 電子取引データ保存（メール添付の請求書、Web からダウンロードした領収書、カード・銀行の明細データ、Stripe の請求書など） | 義務 | v1 の証憑モジュールで満たす（3.2） |
| 電子帳簿等保存（会計ソフトで作った帳簿を電子のまま保存） | 任意。「優良な電子帳簿」なら過少申告加算税 5% 軽減 | 最低限の要件を v1 で満たし、優良の要件も設計に含める（3.3）。届出は [09 D17](09-decisions.md) |
| スキャナ保存（紙の原本をスキャンして紙を捨てる） | 任意 | 行わない。紙の領収書は原本を 7 年保管し、写真は帳簿づけの補助（3.4） |

### 3.2 電子取引データ保存（義務）

| 要件 | 満たし方 |
| --- | --- |
| 真実性（4 つの措置のいずれか） | **事務処理規程方式**（訂正・削除の防止に関する事務処理規程を定めて運用）。加えてシステム側で証憑を上書き・削除できない設計（`Document` は追記のみ、無効化は論理削除・理由つき・履歴あり、SHA-256）。タイムスタンプは使わない |
| 可視性 | 画面と PDF で表示・印刷できる。操作説明書（オンラインヘルプで可）と **システム概要書**（自社開発では必須）はこのリポジトリの `docs/` が担う |
| 検索 | 取引年月日・取引金額・取引先で検索、日付・金額は範囲指定、2 項目以上の組み合わせ。新設法人は第 1 期・第 2 期は検索要件が不要、第 3 期以降も売上高 5,000 万円以下なら不要（ダウンロードの求めに応じられること）だが、**v1 から実装する** |
| 保存期間 | 7 年（欠損金が生じた期は 10 年）。起算日は申告期限の翌日 |

- 保存対象には **ネットバンキングの振込データやカードの利用明細データ自体** も含まれる。取込に使った CSV は証憑（`statement`）として保存し、Stripe の月次の請求書もダウンロードして保存する。
- 猶予措置（相当の理由）はあるが、本システムで要件を満たすので頼らない。
- JIIMA 認証は市販ソフト向けで自作は対象外。代わりに「要件対応表（規則 → 機能 → 証跡）」を `docs/ops/electronic-records-compliance.md` として保管する（§9）。

### 3.3 電子帳簿（最低限と優良）

| 要件 | 満たし方 |
| --- | --- |
| システム関係書類（概要書・仕様書・操作説明書・事務手続書） | `docs/design/`（概要・仕様）、`docs/ops/`（操作・事務手続）。版は git の履歴 |
| 見読性・ダウンロードの求め | 画面・PDF・CSV。設定 › 書き出し で全データを出せる |
| 訂正・削除・追加の履歴（優良） | 直接訂正を禁止し反対仕訳で訂正（元仕訳の番号つき）。追加入力は `createdAt` で分かる。入力日から 1 週間以内の訂正は規程で履歴省略可だが、本システムは常に残す |
| 帳簿間の相互関連性（優良） | 仕訳番号 `JournalEntry.no` を仕訳帳・総勘定元帳・固定資産台帳・請求書で共有する |
| 検索（優良） | 取引年月日・金額・取引先で範囲・組み合わせ検索（仕訳の一覧） |
| 対象帳簿 | 仕訳帳・総勘定元帳・補助簿・固定資産台帳・消費税の帳簿。固定資産台帳の訂正も履歴を残す |

優良な電子帳簿の適用を受けるには法定申告期限までに届出書を出す（[09 D17](09-decisions.md)）。

### 3.4 スキャナ保存を行わない理由

自社システムでは総務大臣認定のタイムスタンプが必須で、訂正削除履歴システムによる代替要件を自社だけでは満たせない。紙の領収書は月ごとに封筒で原本を 7 年保管する運用にし、写真は帳簿づけと検索の補助とする。将来やるなら認定タイムスタンプ事業者の API 連携（v3 以降）。

### 3.5 2027-01-01 以降の新制度

デジタルシームレス保存（Peppol の電子インボイスや銀行決済データを改ざんできない形で自動保存し、事前に届け出ると重加算税の加重を免れる）は任意。銀行 API を直結する v2 以降で検討する。

## 4. 法人税・地方税と申告

### 4.1 税率と制度（第 1 期・第 2 期）

| 項目 | 内容 | 設計 |
| --- | --- | --- |
| 法人税の軽減税率（所得 800 万円以下 15%） | 2027-03-31 までに開始する事業年度が対象。第 1 期は 15%（800 万円は月割）、第 2 期は現行法では 19%。延長は令和 9 年度改正次第 | 税率は事業年度の開始日で引く日付つきパラメータ |
| 防衛特別法人税 | 2026-04-01 以後に開始する事業年度から。第 1 期から対象で、税額 0 でも申告（零申告）が要る | 申告用の下書きに欄を持つ |
| 地方法人税 | 法人税額の 10.3% | 同上 |
| 法人住民税の均等割 | 神奈川県 2 万円 + 鎌倉市 5 万円（年額。赤字でも課税。事業年度が 1 年未満は月割、1 か月未満の端数は 1 か月） | 決算整理の法人税等に自動計上 |
| 法人事業税・特別法人事業税 | 所得割（400 万円以下 3.5% など）＋特別法人事業税。最新の率は要確認 | 日付つきパラメータ |
| 中間申告 | 前期の法人税額が 20 万円超（6 か月換算 10 万円超）なら 11 月末。第 1 期はなし | カレンダーで判定 |

### 4.2 申告の分担（申告書は自作しない）

e-Tax の API は参照のみで送信できず、申告書の様式は毎年変わる。本システムは次を出力し、申告書本体は e-Tax ソフトへの取込と画面入力、または税理士に渡す（[09 D6](09-decisions.md)）。

- 財務諸表 CSV（HOT010 Ver.3.0。BS・PL・株主資本等変動計算書・個別注記表）
- 勘定科目内訳明細書 CSV（預貯金・売掛金・買掛金・未払金・借入金・役員報酬など）
- 別表十六(七)（少額減価償却資産）などの明細 CSV と、固定資産の償却計算の元データ
- 別表四・五(一)の申告調整の下書き（役員給与・交際費・減価償却超過・繰延資産・租税公課）と税額の概算
- eLTAX（法人住民税・事業税）に入力する課税標準と均等割の月割
- 出力は国税庁の CSV ファイルチェックコーナーでの合格を受入基準にする

## 5. 固定資産と減価償却

| 区分 | 取得価額 | 処理 | 償却資産税 |
| --- | --- | --- | --- |
| 少額減価償却資産 | 10 万円未満 | 取得時に全額費用 | 対象外 |
| 一括償却資産 | 20 万円未満 | 3 年均等（月割） | 対象外 |
| 中小企業者等の特例 | 40 万円未満（2026-04-01 以後の取得。以前は 30 万円） | 全額損金。青色申告・従業員 400 人以下・年 300 万円まで（第 1 期は月割で約 125 万円）・2029-03-31 まで・別表十六(七) | **対象（国税だけの特例）** |
| 通常 | 上記以外 | 法定耐用年数で償却。建物・建物附属設備・ソフトウェアは定額法、器具備品は届出がなければ定率法 | 対象 |

- 判定は経理方式に従う（免税の期は税込額）。取得日で 30 万円 / 40 万円を切り替える。
- 償却方法の届出書（定額法にしたい場合）は第 1 期の申告期限（2027-05-31）まで。届出なしで定額法を使おうとしたら警告する。
- 償却資産の申告は毎年 1 月 1 日時点の所有分を 1 月 31 日までに鎌倉市へ（免税点 150 万円未満でも申告）。2026 年 11〜12 月に取得した資産は 2027 年の申告対象。
- 固定資産台帳は電子帳簿の対象なので、訂正の履歴を残す。

## 6. 会社法の計算書類と決算公告

- 成立の日の貸借対照表（開始貸借対照表）を作る。開始仕訳から自動で出す。
- 各期の計算書類は貸借対照表・損益計算書・株主資本等変動計算書・個別注記表に、事業報告と附属明細書（固定資産・引当金・販管費の明細）。会計帳簿に基づいて作り、10 年保存。
- 取締役会なし・監査役なしなので、取締役が定時株主総会に提出して承認を受ける。株主 1 人なら書面決議（同意書面を 10 年本店備置）。本システムは議事録・同意書面のひな形と承認日の記録を持つ。
- 個別注記表の必須項目は限られる（重要な会計方針、会計方針の変更、表示方法の変更、誤謬の訂正、株主資本等変動計算書に関する注記、その他）。ひな形を用意し、中小企業の会計に関する基本要領に拠る旨を書く。
- 決算公告は資本金 5 万円でも義務。定款で電子公告にしておけば、貸借対照表の全文を自社サイトに定時株主総会の後 5 年間掲載するだけでよく、電子公告調査も不要（[09 D10](09-decisions.md)）。本システムは公告用の HTML を書き出し、掲載日と掲載期限を管理する。

## 7. 役員報酬・社会保険・源泉徴収（運用は今から、計算機能は v3）

- 役員報酬は期首から 3 か月以内に決め、定期同額で払う。期中の改定は原則不可（警告する）。賞与は事前確定届出給与（新設法人は設立から 2 か月以内に届出）。
- 報酬を払うなら社会保険は強制（設立から 5 日以内に新規適用）。協会けんぽ神奈川の 2026 年度は健保 9.92%・介護 1.62%・子ども・子育て支援金 0.23%・厚生年金 18.3%。報酬ゼロなら適用を受けられない。
- 源泉所得税は納期の特例（7/10・1/20）を申請する。2026 年 12 月の年末調整は令和 8 年度改正後の控除（給与所得控除の最低保障 74 万円など）で計算し、2027 年 1 月以降は令和 9 年分の税額表。
- 住民税の特別徴収は給与支払報告書の提出後、翌年 6 月から。市からの通知額を入力する（自社計算しない）。
- 給与計算そのものは v3。v1〜v2 では、税理士や国税庁の年調ソフトで計算した結果を仕訳（役員報酬 / 預り金 / 法定福利費 / 普通預金）として登録する。

| 2027-06-30 まで | 定時株主総会（計算書類の承認）、決算公告 | 自社 |

システムは設立日から上の期限を生成し（休日の繰り延べ、応当日の規則を共通関数で）、提出日と受付の状況を記録する。

## 9. 要件対応表（規則 → 機能 → 証跡）

JIIMA 認証の代わりに、税務調査で示せる対応表を `docs/ops/electronic-records-compliance.md` に保つ。v1 の S6 で雛形を作る。

| 要件 | 機能 | 証跡 |
| --- | --- | --- |
| 電子取引データの真実性 | 事務処理規程、追記のみの証憑、SHA-256、監査ログ | 規程の実物（非公開側）、`Document` と `AuditLog` のスキーマ、この文書 |
| 検索要件 | 証憑と仕訳の検索（日付・金額・取引先、範囲、組み合わせ） | 証憑画面、書き出しの索引 CSV |
| システム関係書類 | `docs/design/`、`docs/ops/` | git の履歴 |
| 帳簿の訂正履歴・相互関連性 | 反対仕訳、`no`、`reversalOfId`、固定資産台帳の履歴 | `packages/ledger` の不変条件テスト、DB トリガー |
| 保存期間 | 論理削除のみ、GCS の保持、日次エクスポート | バックアップの設定 |

## 10. 税理士・社労士に確認する事項

- インボイス登録の是非と時期、簡易課税か本則か（[09 D1・D2](09-decisions.md)）。登録だけで課税事業者になる場合の 2 年縛りの有無。
- 創立費・開業費の償却の時期（[09 D11](09-decisions.md)）、設立前の課税仕入の扱い。
- 役員報酬の額と開始月、報酬ゼロにする場合の届出の要否（[09 D9](09-decisions.md)）。
- 第 1 期の申告を自力で行うかスポットで依頼するか（[09 D6](09-decisions.md)）。
- 神奈川県・鎌倉市の最新の税率、令和 9 年度税制改正（2026 年 12 月の大綱）で変わる項目。
