# 07. 運用

設立直後・毎月・毎年のルーチンと、システムが暦として持つ期限を定めます。期限の根拠は [03](03-compliance.md) と `docs/research/jp-requirements.md`。税務・社会保険の判断は税理士・社労士の確認を前提にします。

## 1. 設立直後（2026-11）

| 順 | すること | システム |
| --- | --- | --- |
| 1 | 法人口座を開く（[09 D3](09-decisions.md)）。開設までは役員の個人口座で立替 | 口座「役員立替」を作る |
| 2 | 事業所・会計期間（設立日〜2027-03-31）・勘定科目・税区分・セグメントを初期化 | 設定 › 初期化ウィザード |
| 3 | 開始仕訳: 資本金の払込、創立費（登録免許税・定款）、設立前の立替 | 取引 › 伝票 |
| 4 | Stripe の 2 アカウントの事業者情報を法人へ切り替え、読み取り専用キーを発行して登録 | 設定 › 口座 › Stripe |
| 5 | 税務署・県税事務所・市役所への届出（法人設立届出書、青色申告承認申請書、給与支払事務所等の開設届出書、源泉所得税の納期の特例）。年金事務所（役員報酬を払うなら） | 期限を暦に登録 |
| 6 | 役員報酬を決める（設立から 3 か月以内） | 定期取引に登録 |
| 7 | 事務処理規程（電子取引データ保存）を確定して保存 | 設定 › 証憑の規程 |
| 8 | 自動登録ルールの初期セット（家賃・GCP・Stripe 手数料・振込手数料・payout） | 設定 › ルール |

## 2. 月次（月初 5 営業日）

| 順 | すること | 目安 |
| --- | --- | --- |
| 1 | CSV を取り込む（銀行・カード）。Stripe は自動 | 10 分 |
| 2 | 明細を上から片付ける（登録・振替・無視）。ルールを育てる | 20 分 |
| 3 | 証憑の受信箱を空にする（紐づけ・無効） | 10 分 |
| 4 | 口座残高が明細の残高と一致することを確認（ホームの警告がないこと） | 5 分 |
| 5 | 前月を締める（設定 › 会計期間 › 締め） | 1 分 |
| 6 | ホームで現預金・セグメント損益・資金繰りを見る | 5 分 |

締めた後に証憑が届いたら、受け取った月の日付で登録し、摘要に対象月を書く。

## 3. 随時

- 受託の請求書は納品時に発行し、入金は明細から消し込む（v2）。
- 個人への業務委託の報酬は源泉徴収の要否を確認し、預り金を計上する。
- 10 万円以上の備品・内装は固定資産台帳に登録する。
- 新しい取引先には登録番号を入れ、照合する（v2）。

## 4. 年間の暦（3 月決算）

システムは会計期間から次の期限を生成し、7 日前と当日にメールする。実際の期日は年ごとの暦（土日祝）でずれる。

| 期限 | 内容 | 宛先 |
| --- | --- | --- |
| 設立日から 2 か月以内 | 法人設立届出書 | 税務署 |
| 設立日から 3 か月を経過した日の前日（例: 11/10 設立 → 2027-02-09） | 青色申告承認申請書（少額減価償却資産の特例の前提。最優先） | 税務署 |
| 設立日から 1 か月以内 | 給与支払事務所等の開設届出書 | 税務署 |
| 随時（提出翌月から適用） | 源泉所得税の納期の特例の承認申請 | 税務署 |
| 設立日から 5 日以内（役員報酬を払う場合） | 健康保険・厚生年金 新規適用届（報酬ゼロなら適用を受けられない） | 年金事務所 |
| 設立から 30 日以内（鎌倉市）・2 か月以内（神奈川県） | 法人設立・開設届出書 | 市役所・県税事務所 |
| 設立から 2 か月以内 | 事前確定届出給与に関する届出書（役員に賞与を出す場合） | 税務署 |
| 第 1 期末（2027-03-31） | 適格請求書発行事業者の登録申請（設立日に遡る場合）、簡易課税制度選択届出書 | 税務署 |
| 第 1 期の申告期限（2027-05-31） | 減価償却資産の償却方法の届出書（定額法にしたい資産がある場合） | 税務署 |
| 毎年 1/20 | 源泉所得税（納期の特例・7〜12 月分） | 税務署 |
| 毎年 1/31（2027 年は 2/1） | 法定調書合計表・支払調書、給与支払報告書、償却資産申告書（免税点未満でも申告） | 税務署・市区町村 |
| 毎年 5/31 | 法人税・地方法人税・防衛特別法人税（零申告を含む）・法人住民税・法人事業税の申告と納付、消費税（課税事業者） | 税務署・県税事務所・市役所 |
| 毎年 6 月末まで | 定時株主総会（計算書類の承認。1 人なら書面決議）、決算公告（電子公告なら BS 全文を 5 年間掲載） | 自社 |
| 毎年 7/10 | 源泉所得税（納期の特例・1〜6 月分）、算定基礎届（社会保険） | 税務署・年金事務所 |
| 毎年 11 月末 | 法人税・消費税の中間申告（前期の税額が一定額を超えた場合） | 税務署 |
| 毎月 10 日 | 源泉所得税（納期の特例がない場合）、住民税の特別徴収 | 税務署・市区町村 |
| 毎月末 | 社会保険料の納付（口座振替） | 年金事務所 |

## 5. 決算（4〜5 月）

1. 3 月分の月次を締める。
2. 決算画面のチェックリスト（[02 §5](02-accounting-rules.md)）を上から進める。
3. 決算書 PDF と申告用データ（財務諸表 CSV・勘定科目内訳の元データ・固定資産台帳・消費税集計）を書き出す。
4. 申告（自力または税理士）。納付。
5. 期を `closed` にし、株主総会の同意書面（書面決議・10 年保存）と決算公告（HTML の書き出しと掲載日）を残す。
6. 翌期の設定（消費税の区分・役員報酬・ルールの棚卸し）。

## 6. 保全

| 項目 | 頻度 | 内容 |
| --- | --- | --- |
| 日次エクスポート | 毎日 | 仕訳・明細・設定を GCS へ。非公開 git にも積む（[06 §6](06-architecture.md)） |
| 復元訓練 | 年 1 回 | local に復元して試算表が一致することを確認 |
| 鍵の更新 | 年 1 回 | Stripe の制限付きキー、銀行 API のキー |
| 監査ログの確認 | 月次 | 自分以外の actor がないこと、想定外の取消がないこと |
| 保存期間 | 常時 | 帳簿・証憑は 7 年（欠損金の期は 10 年）。期限より前に消さない |

## 7. 税理士への受け渡し

書き出しメニューから 1 つの zip にまとめる: 仕訳帳 CSV（freee / 弥生形式）、総勘定元帳 CSV、試算表、固定資産台帳、消費税集計、証憑一式（証憑 ID と仕訳番号の対応表つき）、決算書 PDF。
