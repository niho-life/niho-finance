# 09. 判断事項

オーナーの判断が要る項目を、推奨案つきで並べます。決まったものは `docs/decisions/` に 1 件 1 ファイル（`YYYY-MM-DD-<slug>.md`: 状況 / 決定 / 理由 / 影響）で記録し、この表の状態を更新します。税務・社会保険の判断は税理士・社労士の確認を前提にします（この文書は助言ではなく論点の整理です）。

| # | 論点 | 選択肢 | 推奨 | 状態 |
| --- | --- | --- | --- | --- |
| D1 | インボイス（適格請求書発行事業者）に登録するか | A 第 1 期は登録しない（免税のまま）/ B 設立時に登録（課税事業者になる）/ C 受託の顧客が求めた時点で登録 | **C**。①②の顧客は主に消費者で登録番号を求められない。③の B2B 顧客が仕入税額控除のために求めたら登録する。システムは期の途中の切替に対応する | 未決 |
| D2 | 消費税の方式（登録した場合） | 本則課税 / 簡易課税（第 5 種・みなし仕入率 50%） | 売上の構成と経費の割合で税理士と判断。システムは両方の集計を出す | 未決 |
| D3 | 法人口座の銀行 | GMO あおぞらネット銀行 / 三井住友（Web21）/ 他 | **GMO あおぞら**（自社口座への API が無償で公式に用意され、sunabar で先に開発できる。契約まで最大 2 か月なので設立直後に申込）。v1 は CSV、v2 で API。[04 §2](04-integrations.md) | 未決 |
| D4 | Stripe アカウント | A 既存 2 アカウント（platform と、OAuth 接続の Standard 連結アカウント）の名義を法人に変える / B 法人名義で新規作成し、旧アカウントは読み取り専用で残す | **まず Stripe サポートへ書面で A の可否を確認**。日本で本人確認済みのアカウントは個人 → 法人の編集ができず新規作成が公式の案内なので、不可なら **B**（platform を作り替えるなら Connect の再構築と連結の再接続）。いずれも Organizations で束ね、組織の読み取り専用キーで取り込む。[04 §1.1](04-integrations.md) | 未決 |
| D5 | 自社拠点の application fee | A 0 にする / B 内部取引（会社全体では相殺）として記帳 | **A**。売上が二重に膨らまず、免税判定の売上高にも影響しない。B はセグメント損益に手数料を見せたい場合 | 未決 |
| D6 | 第 1 期の申告 | A 決算書まで自作し申告書は e-Tax ソフトで自力 / B 決算書まで自作し申告書は税理士にスポット依頼 / C 税理士に決算から依頼 | **B**（初年度だけ）。2 期目以降は A を目指す | 未決 |
| D7 | GCP の置き場 | A 既存の本番プロジェクトに同居（Cloud SQL も同居）/ B 専用プロジェクト | **A**。固定費ゼロで始め、必要になったら移す | 未決 |
| D8 | 非公開側 `niho-finance-core` | A ローカルフォルダ / B 最初から非公開リポ | v1 配備までは **A**、日次エクスポートを受け始めたら **B**（0 円で履歴が残る） | 未決 |
| D9 | 役員報酬 | 金額と開始月（設立から 3 か月以内に決める。0 円なら社会保険の加入対象外） | 税理士・社労士と判断。システムは定期取引として記録するだけ | 未決 |
| D10 | 決算公告の方法 | 官報 / 日刊紙 / 電子公告（自社サイト） | **電子公告**。定款の公告方法を電子公告にしておく（決算公告は電子公告調査が不要）。BS の要旨を niho.life に掲載する | 未決（定款作成時） |
| D11 | 設立前後の費用 | 創立費・開業費を繰延資産として計上し、償却の時期（初年度一括 / 5 年）を選ぶ | 税理士と判断。システムは両方を扱う。資本金（5 万円）より設立費用（登録免許税 15 万円＋定款）が大きいので、差額は役員借入金 | 未決 |
| D12 | 拠点の現金 | A 現金を受け取らない / B 拠点ごとに現金口座を持ち、週次で数える | 現状の運用に合わせる。B なら現金出納の画面を v1 に含める | 未決 |
| D13 | ライセンス | A 非公開ライセンス（niho-docs と同じ）/ B OSS（MIT など） | **A** で開始。公開範囲が落ち着いたら B を検討 | 未決 |
| D14 | 配色 | A NIHO の semantic token とブランド色 / B 独自 | **A**。統一感と実装の速さ | 未決 |
| D15 | 会計期間の第 1 期 | 設立日〜2027-03-31（freee の試用で 2026-04-01 始まりになっているが、設立前は含めない） | 設立日始まり | 確認待ち |
| D16 | 売上の計上日（Stripe） | A 決済日 / B 役務提供の期間で按分（前受金） | **A**。月会費は決済日の売上とし、期をまたぐ分だけ決算整理で前受に振り替える | 未決 |

決まったら、該当する設計書を直し、Issue に反映します。
